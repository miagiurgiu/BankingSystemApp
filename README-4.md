# Java Banking System

A small console project for practising Java OOP.

## Currently Demonstrated

- Creates a bank, two customers and four accounts
- Links each account to its owner
- Withdraws money from a current account
- Displays savings and current accounts through polymorphism
- Adds customers to the bank and displays their accounts

## Implemented but Not Used in `Main`

- Deposits and transaction descriptions through method overloading
- Insufficient-funds and overdraft-limit checks
- Savings interest calculation
- Email validation and formatted person introduction
- Account removal and overloaded account construction

## Current Limitations

- `accountCount` is declared but is not incremented or displayed
- The bank account list is not displayed and currently receives only Mia's accounts

## OOP Concepts

Encapsulation, inheritance, polymorphism, constructors, overloading, overriding, association and aggregation.

Run `Main.java` to start the example.
